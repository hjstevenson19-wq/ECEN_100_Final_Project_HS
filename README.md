This project is an IoT workbench monitor. Desired function include the following:

- Record temperature and humidity
- Scan light levels
- Check for motion and if someone is standing nearby
- Wirelessly control a bench lamp with magnifier
- Wirelessly control a DIY fume extractor

I am using the following peripherals:

- LM737 Photosensitive Resistor Module
- DHT22 Temperature and Humidity Sensor
- HC-SR501  Passive Infrared Sensor
- VL53L0X Time of Flight Sensor
- 2 Channel Relay Module

The libraries I used include the following

-  Adafruit ST7735 Library
-  Adafruit_VL53L0X Library
-  DHT Sensor Library
